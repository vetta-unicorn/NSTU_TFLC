Цикл do-while в языке PHP – это блок кода, предназначенный для итерационного выполнения определенных действий, пока соблюдается заданное условие.

Для объявления цикла do-while в языке PHP используются ключевые слова do и while, а также специальный синтаксис. После do в фигурных скобках идет блок действий, далее ключевое слово while и условие в круглых скобках, цикл завершает точка с запятой.

Формат записи: do {идентификатор, унарная операция, точка с запятой} while (идентификатор1, операция сравнения, идентификатор2);

do {идентификатор, унарная операция, точка с запятой} while (идентификатор1, операция сравнения, идентификатор2);

В связи с разработанной контекстно-свободной грамматикой G[<F>] синтаксический анализатор (парсер) создания функции будет считать верными следующие записи функций:

1) do { $a++; } while ($a != 4);
2) do { $z--; } while ($z > $y);
3) do { $d--; } while ($i <= 8);
