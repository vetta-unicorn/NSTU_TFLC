**Решение первой задачи**

*а. Описание задачи:*
Построить РВ, описывающее формат имени файла .doc, .docx, .pdf,  .jpg, .jpeg, .png, .gif

*b. Регулярное выражение:* ^.+\.(doc|docx|pdf|jpg|jpeg|png|gif)$

^ - проверка идет с начала строки; . - любой символ; + - повторение может быть один или более раз; \. - экранированная точка (точка в имени файла); ( ) - группировка (позволяет выбрать несколько вариантов); | - выбор одного из вариантов; $ - конец строки.

*с. Примеры строк, которые должны находиться:* r.jpeg, test.doc, pic.png

*b. Регулярное выражение:* -?\d+(?:[.,]\d+)?

- - минус; ? - повторение 0 или 1 раз; \d - любая цифра; + - один или более раз; (?: ) - применение ? ко всей дробной части; [.,] - точка или точка с запятой.

*b. Регулярное выражение:* ^(?=.*[А-ЯЁ])(?=.*[а-яё])(?=.*\d)(?=.*[()#?!|@$%^&*\-_.]).{14,}$

^ - начало строки; (?=  ) - позитивный просмотр вперед (проверяет что после текущей позиции существует подходящая подстрока); .* - любые символы; *[А-ЯЁ] - есть одна заглавная буква во всей строке; *[а-яё] - есть одна строчная буква во всей строке; \d - любая цифра; [()#?!|@$%^&*\-_.] - набор специальных символов; .{14,} - любой символ повторенный 14 или более раз; $ - конец строки.

*с. Примеры строк, которые должны находиться:* !@145МойСложныйПароль1231, пАрОлЬ11@нОВЫй13!

**Грамматика BNF**

<оператор do while> ::= "do" <блок> "while" "(" <условие> ")" ";"

<блок> ::= "{" <список операторов> "}" | <оператор>

<список операторов> ::= <оператор> | <список операторов> <оператор>

<оператор присваивания> ::= <токен> "=" <условие> ";"

<оператор инкремента> ::= <токен> "++" ";"

<оператор декремента> ::= <токен> "--" ";"

<токен> ::= "$" <идентификатор>

<условие> ::= <сравнение>

<сравнение> ::= <арифметическое выражение> | 
<арифметическое выражение> "<" <арифметическое выражение> | <арифметическое выражение> ">" <арифметическое выражение> | <арифметическое выражение> "<=" <арифметическое выражение> | <арифметическое выражение> ">=" <арифметическое выражение> | <арифметическое выражение> "==" <арифметическое выражение> | <арифметическое выражение> "!=" <арифметическое выражение>

<арифметическое выражение> ::= <слагаемое> | 
<арифметическое выражение> "+" <слагаемое> | 
<арифметическое выражение> "-" <слагаемое>

<слагаемое> ::= <множитель> | <слагаемое> "*" <множитель> | <слагаемое> "/" <множитель>

<множитель> ::= <число> | <переменная> | "(" <выражение> ")"

<идентификатор> ::= <буква> { <буква> | <ц> | "_" }

<число> ::= <ц> { <ц> }

<буква> ::= "a" | "b" | ... | "z" | "A" | ... | "Z"

<ц> ::= "0" | "1" | ... | "9"
